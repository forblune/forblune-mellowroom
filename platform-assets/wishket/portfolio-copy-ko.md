# 위시켓 포트폴리오 입력안

## 제목

밝은 로컬 서비스 한·영 예약·운영 웹 데모 구축

## 업무 범위

- 개발
- 디자인
- 기획

## 추천 분야

- 퍼블리싱·반응형
- 랜딩·소개 페이지
- 기타(웹사이트 구축)

## 관련 기술

HTML, CSS, JavaScript, Responsive Web, Playwright, Cloudflare Workers

## 고객사 및 역할

- 고객사: 자체 프로젝트
- 역할: 기획·디자인·프론트엔드 개발·반응형 QA·배포

## 결과물 URL

https://mellowroom.forblune.com

## 프로젝트 상세

1. 포트폴리오 소개

밝고 차분한 지역 웰니스 서비스를 가정해 프로그램 비교부터 예약, 예약 후 운영 상태까지 연결한 한국어·영어 전환형 웹 포트폴리오입니다. 실제 고객사·영업장·후기·매출·예약 실적을 나타내지 않는 자가 기획 콘셉트이며, 로컬 서비스 웹을 어떤 방식으로 설계하고 검증하는지 보여주기 위해 제작했습니다.

2. 작업 범위

1인 프로젝트로 서비스 구조와 사용자 흐름 기획, 밝은 편집형 UI, 한·영 전환, 반응형 프론트엔드 개발, Cloudflare 커스텀 도메인 배포, 데스크톱·태블릿·모바일 QA를 담당했습니다. 첫 화면에는 가상의 공간 사진 대신 실제 예약 데모와 같은 일정표 UI를 배치해 작업 범위가 바로 보이게 구성했습니다.

3. 주요 업무

- 프로그램별 소요시간·예시 가격·설명 비교 화면 구성
- 프로그램→날짜→시간→연락처 검증→확인으로 이어지는 예약 데모 구현
- 정보 미입력 시 한국어·영어 오류 안내와 키보드 포커스 처리
- 신규·확정·변경 요청 상태를 보여주는 운영자 화면 예시 구현
- 390·768·1440px 반응형 화면과 한·영 전환 검증
- Cloudflare Workers와 `mellowroom.forblune.com` 커스텀 도메인 배포

4. 주요 중점 사항

복잡한 기능보다 처음 방문한 고객이 서비스, 가격, 소요시간, 다음 행동을 빠르게 이해하도록 정보 순서를 단순화했습니다. 고객 입력은 서버로 전송하지 않는 데모로 구성했고, 실제 고객 성과나 판매 실적을 과장하지 않도록 자가 기획 포트폴리오 경계를 화면에 명시했습니다. 공개 배포 후 3개 화면 폭에서 가로 넘침 0, 콘솔 오류 0, 예기치 않은 외부 요청 0을 확인했습니다.
