# Mellow Room

A bright, bilingual local-wellness booking and operations portfolio concept by Forblune.

## Truth boundary

- This is a self-initiated interactive portfolio, not paid client work.
- Mellow Room is a fictional studio name for the demo.
- Names, bookings, prices, hours, location details, and operating states are sample data.
- The project makes no claims about real clients, testimonials, traffic, ranking, revenue, or conversions.
- The booking flow stores nothing and sends nothing to a server.

## What it demonstrates

- Korean and English content without a separate profile or route.
- Bright local-service art direction that complements Forblune's dark product and operations demos.
- Service comparison, transparent example pricing, four-step booking interaction, validation, and confirmation.
- A lightweight owner view for new, confirmed, and change-request appointment states.
- Responsive behavior for desktop, tablet, and mobile.
- Custom-domain deployment through Cloudflare Workers static assets.
